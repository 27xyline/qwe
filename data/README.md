# Муниципальное население

Источник: Росстат, БД ПМО, показатель `8112027`, срез `2025-01-01`.

1. Получите из [БД ПМО](https://rosstat.gov.ru/storage/mediabank/munst.htm) строки только для муниципальных районов, муниципальных и городских округов; поселения исключите.
2. Сохраните их в `data/municipal-population-2025.csv` в кодировке UTF-8 и с колонками: `region_id;rosstat_name;municipality_type;population;as_of;indicator_code`.
3. Занесите неоднозначные названия в `municipal-population-aliases.json` как `"region_id:имя_контура": "имя_Росстата"`.
4. Укажите дату выгрузки и её checksum в `municipal-population-source.json`.
5. Запустите `npm run data:population`.

Импортёр прекращает работу при пропущенной, лишней или повторно использованной строке, неверной дате или коде показателя, нецелом населении и при любом изменении геометрии. Файлы карты записываются только после полной проверки всех регионов.

# Муниципальное население

Источник населения: Росстат, БД ПМО, показатель `8112027`, срез `2025-01-01`. Нормализованная выборка содержит 531 муниципальный район, муниципальный и городской округ в 18 регионах.

Источник геометрии и параметры её подготовки зафиксированы в `municipal-boundaries-2025-source.json`.

1. Сохраните строки в `data/municipal-population-2025.csv` в UTF-8 и с колонками: `region_id;rosstat_name;municipality_type;population;as_of;indicator_code`.
2. Укажите дату выгрузки и её checksum в `municipal-population-source.json`.
3. Запустите `npm run data:population`.
4. При обновлении геометрии передайте путь к GeoJSON муниципальных границ 2025 года: `npm run data:boundaries -- /путь/к/границам.geojson`.

Импортёр прекращает работу при пропущенной, лишней или повторно использованной строке, неверной дате или коде показателя, нецелом населении и при любом изменении геометрии. Файлы карты записываются только после полной проверки всех регионов.

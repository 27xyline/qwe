# Карта населения одиннадцати областей

Интерактивная векторная карта для просмотра населения и плотности населения по муниципалитетам Московской, Тверской, Владимирской, Калужской, Тульской, Рязанской, Ярославской, Смоленской, Костромской, Ивановской и Нижегородской областей.

## Что можно посмотреть

- 353 муниципальных образования на векторной карте: 56 в Московской, 42 в Тверской, 19 во Владимирской, 26 в Калужской, 26 в Тульской, 29 в Рязанской, 20 в Ярославской, 27 в Смоленской, 30 в Костромской, 27 в Ивановской и 51 в Нижегородской области;
- переключение между населением и плотностью населения (чел./км²);
- карточку выбранного округа с площадью, населением и плотностью;
- 10 крупнейших городов: их население и плотность соответствующего округа;
- подбор баз БПЛА с точками-кандидатами во всех одиннадцати областях;
- контурные границы и полупрозрачные подписи регионов, а также сводку по населению, площади и количеству муниципалитетов.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который появится в терминале (обычно `http://localhost:3000`).

## Данные

Границы муниципалитетов и распределение населения подготовлены как GeoJSON-подобные векторные данные. Витрина использует муниципальные итоги на 01.01.2025; для четырёх добавленных областей границы получены из открытого набора geoBoundaries (OSM, границы 2017 года), а итоговое население распределено по муниципалитетам для демонстрации аналитических режимов. Пространственная детализация Московской области основана на GHS-POP 2020.

Файлы данных находятся в `public/data/` и включают по одному GeoJSON-подобному файлу для каждой из одиннадцати областей.

Каждый объект содержит идентификатор и название территории, геометрию, площадь в км², население и рассчитанную плотность. Поэтому данные можно использовать не только для отображения, но и в аналитике или моделях.

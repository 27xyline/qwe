# Карта населения трёх областей

Интерактивная векторная карта для просмотра населения и плотности населения по муниципалитетам Московской, Тверской и Владимирской областей.

## Что можно посмотреть

- 117 муниципальных образований на векторной карте: 56 в Московской, 42 в Тверской и 19 во Владимирской области;
- переключение между населением и плотностью населения (чел./км²);
- карточку выбранного округа с площадью, населением и плотностью;
- 10 крупнейших городов: их население и плотность соответствующего округа;
- подбор баз БПЛА с точками-кандидатами во всех трёх областях.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который появится в терминале (обычно `http://localhost:3000`).

## Данные

Границы муниципалитетов и распределение населения подготовлены как GeoJSON-подобные векторные данные. Витрина использует муниципальные итоги на 01.01.2025: Мосстата для Московской области, Тверьстата для Тверской и Владимирстата для Владимирской. Пространственная детализация Московской области основана на GHS-POP 2020.

Файлы данных находятся в `public/data/moscow-oblast-municipalities.json`, `public/data/tver-oblast-municipalities.json` и `public/data/vladimir-oblast-municipalities.json`.

Каждый объект содержит идентификатор и название территории, геометрию, площадь в км², население и рассчитанную плотность. Поэтому данные можно использовать не только для отображения, но и в аналитике или моделях.

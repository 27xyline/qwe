# Карта населения восемнадцати регионов

Интерактивная векторная карта для просмотра населения и плотности населения по муниципалитетам восемнадцати регионов: одиннадцати областей Центральной России, Вологодской, Брянской, Орловской, Липецкой и Тамбовской областей, Республики Мордовия и Чувашской Республики.

## Что можно посмотреть

- 531 муниципальное образование на актуальной векторной карте восемнадцати регионов;
- переключение между населением и плотностью населения (чел./км²);
- карточку выбранного округа с площадью, населением и плотностью;
- 10 крупнейших городов: их население и плотность соответствующего округа;
- подбор баз БПЛА с точками-кандидатами во всех восемнадцати регионах;
- контурные границы и полупрозрачные подписи регионов, а также сводку по населению, площади и количеству муниципалитетов.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который появится в терминале (обычно `http://localhost:3000`).

## Данные

Население муниципальных районов, муниципальных и городских округов взято из официальной выгрузки Росстата на 01.01.2025. Границы обновлены по OSM-слою муниципальных образований 2025 года, приведены к WGS 84 и упрощены для быстрой отрисовки в браузере. Плотность рассчитывается в приложении как население муниципалитета, делённое на площадь его контура.

Файлы данных находятся в `public/data/` и включают по одному GeoJSON-подобному файлу для каждого из восемнадцати регионов.

Каждый объект содержит название территории, геометрию, код ОКТМО, население и официальное название строки Росстата. Значения в списке городов сохранены как справочные: они не подменяют муниципальную статистику.

## Проверка сборки

```bash
npm run lint
npm run build
```

Папка `dist/` создаётся командой сборки. Для запуска и сборки установите зависимости через `npm install`.
